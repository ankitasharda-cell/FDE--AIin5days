# Five-Day AI Curriculum

Use this skill when the learner wants a structured path through the AI in Five Days program. The five references contain the daily lesson goals, concepts, exercises, and checkpoints:

1. [Day 1 — LLM foundations and prompting](references/day1_foundations.md)
2. [Day 2 — Tools, retrieval, and MCP](references/day2_tools_and_knowledge.md)
3. [Day 3 — Context engineering and reusable skills](references/day3_context_and_skills.md)
4. [Day 4 — Multi-agent systems and Google ADK](references/day4_multi_agent_and_adk.md)
5. [Day 5 — Capstone and evaluation](references/day5_capstone.md)

## How to teach the curriculum

- Find out whether the learner wants to start at Day 1 or jump to a topic. Do not require them to follow the sequence if they have relevant experience.
- Begin each day by agreeing on an achievable outcome and checking prerequisites.
- Use the daily reference as a menu, not a script. Select concepts and exercises based on the learner's goal and available time.
- Keep examples small and explain what the learner should observe. Invite them to adapt the example to their own project.
- Close with the day's checkpoint. If a learner is unsure, revisit the concept with a different example rather than marking it complete.
- Treat provider-specific commands, libraries, and APIs as version-dependent. Verify against official documentation before giving exact setup instructions.
- Encourage learners to use synthetic or public data in exercises and to avoid committing secrets.

## Learning path outcome

By the end, the learner should be able to describe an LLM application's request/response flow, design and test a prompt, connect a model to a bounded tool or knowledge source, manage context, compose simple agents, and evaluate a small AI application for usefulness, reliability, and safety.
